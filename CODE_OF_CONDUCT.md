# Code of conduct

Hmunmawi follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, keep criticism about the work and never about the person, and help make this a welcoming place for everyone, whatever their background, experience or identity. Harassment, insults and personal attacks are not accepted in issues, discussions, pull requests or anywhere else the project lives.

The maintainer may edit or remove comments, close threads, or block people who don't follow this.

To report a problem privately, open a private report on the repository's **Security** tab (**Report a vulnerability**) and start the title with "Conduct:". Only the maintainer can see it, and reports are kept confidential.
